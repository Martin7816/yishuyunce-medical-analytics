# Repository instructions

## Agent skills

### Issue tracker

Issues and specs are tracked in GitHub Issues for `Martin7816/yishuyunce-medical-analytics`. See `docs/agents/issue-tracker.md`.

### Issue task, acceptance, and closure

Before creating, assigning, reviewing, or closing an Issue, read `docs/Issue任务领取与完成说明_V1.0.md`. Every Issue must state the Question, scope, named responsibility for each person, concrete deliverables, dependencies, an acceptance matrix with evidence, closure conditions, and explicit downstream handoffs. A PR merge or verbal agreement alone is not completion.

### Triage labels

Use the default mattpocock/skills triage vocabulary. See `docs/agents/triage-labels.md`.

### Domain docs

Use a single-context domain documentation layout. See `docs/agents/domain.md`.
