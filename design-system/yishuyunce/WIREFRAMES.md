# 重点页面线框

这些线框只冻结信息层级、组件位置和交互路径。数字、点位和颜色块均为 `fixture:design-prototype` 示意，不代表真实数据结论。可打开同目录 `prototype/index.html` 查看静态/fixture 原型。

## 5. 关键路径

1. **大屏演示**：启动 → `/overview` → 切换 stage → 依次讲解 KPI、年龄/支付、医院排行、严重程度、批次状态 → 退出 stage；
2. **医院比较**：`/overview` 医院排行 → `/hospitals` → 选择两家不同机构 → 查看 grouped bar/表格 → 进入医院画像 → 浏览器后退恢复筛选；
3. **费用关系**：`/overview` 收费/成本 → `/costs` → 选择疾病或医院、严重程度 → 先看 KPI/分位数，再看关系图和表格 → 说明相关不等于因果；
4. **风险热力**：`/overview` 严重程度 → `/risks` → 选择年龄/疾病 → 读热力图和矩阵表 → 说明群体统计边界；
5. **失败演示**：加载 → error（code/trace/retry）→ retry → success；合法空结果只显示 empty，不把空数据当成错误。

## 6. 线框验收

| 尺寸 | 检查 |
|---:|---|
| 390px | 单列、无页面级横向滚动、菜单和筛选可键盘/触摸操作、摘要和表格可读 |
| 768px | KPI/图表合理折行、图例不截断、焦点不被固定 UI 遮挡 |
| 1024px | 侧栏与 8 列内容不挤压，单位/版本完整 |
| 1440px | stage/standard 都不新增模块，图表、摘要、表格和边界同屏可追溯 |
