# `/costs` 页面覆盖

## Purpose

说明收费、成本、分位数和住院时长的群体关系。收费是 `Total Charges` 的账面收费，成本是 `Total Costs` 的估算成本，二者不互称。

## Layout

```text
页面标题 + 收费/成本边界 + 版本
└─ 疾病/医院互斥 + 严重程度筛选
   ├─ 记录数 / 收费中位数 / 收费 P90 / 平均成本 KPI
   ├─ 收费分位数 bar
   ├─ scatter：聚合收费 × 住院时长（点大小=病例量，可选分组）
   ├─ 确定性摘要：来源指标 + “相关不等于因果”
   └─ 点位 table：分组、住院时长（天）、收费（美元）、病例量（条）
```

scatter 的每个点必须是后端聚合后的分组，不是单条住院记录。`los=0` 不参与单日金额计算；空图先显示统计边界和“暂无关系数据”，不显示空坐标轴。
