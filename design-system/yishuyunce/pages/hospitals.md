# `/hospitals` 页面覆盖

## Purpose

按 `facility_id` 比较医疗机构的病例量、平均住院时长、收费、成本、急诊率和重症率。医院名称只展示，不作为聚合键。

## Layout

```text
页面标题 + 机构比较边界 + 版本
└─ 医院 A / 医院 B / 比较指标筛选（同院错误提示）
   ├─ A KPI card      ├─ B KPI card
   ├─ grouped_bar：同一指标的 A/B 对照
   ├─ 文字摘要：差异描述 + 相关不等于因果（如涉及关系）
   └─ 可排序比较表（单位、数据版本、来源）
```

`grouped_bar` 最多展示两家机构和一个明确指标；需要同时比较多个指标时拆成可读的指标组，不把不同单位放进同一坐标轴。390px 先显示两张 KPI 和表格，再显示简化图；不使用网络图或地图。
