# `/risks` 页面覆盖

## Purpose

展示年龄、主诊断和严重程度下的住院出院记录群体结构与风险指标；页面不是临床风险评估工具。

## Layout

```text
页面标题 + 群体统计/非诊断边界 + 版本
└─ 年龄组 / 疾病筛选
   ├─ 高风险记录数 / 比例 / 平均住院时长 / 平均收费 KPI
   ├─ heatmap：年龄组 × APR 严重程度，颜色和单元格数字表达记录量/比例
   ├─ severity bar 或 status 摘要
   ├─ 矩阵 table：年龄、严重程度、分子、分母、值、单位
   └─ 固定文案：不构成个人诊断、治疗建议或因果判断
```

heatmap 必须有数值图例、格内文本/符号、键盘焦点和完整矩阵表；不能只用红绿表达“风险”。390px 使用可滚动矩阵或逐行卡片，先给出文字摘要。分母必须由后端按当前筛选记录确定，前端不自行计算。
